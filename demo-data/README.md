# デモ用データ

**登場する会社名・人物名はすべて架空です。実在の企業・団体・個人とは一切関係ありません。**

## フォルダの分け方

```
demo-data/
├── 監視対象/          ← WATCH_ROOT はここを指す。これがシステムに読ませるフォルダ
├── 答え合わせ/        ← 正解表と解説。監視対象の外に置く
└── _原本/            ← 受け取ったままのファイル。整形前の控え
```

**答え合わせを監視対象の中に置かないでください。** 取り込まれてしまい、内容が改正の解説そのものなので必ず「影響あり」と判定されます。

## 監視対象の中身

| 場所 | 役割 |
|---|---|
| `株式会社サクラベース/` | 改正前のまま = **要対応**。デモの主役 |
| `サクラベース・ロジスティクス株式会社/` | 同じグループの別会社。改正対応済み = **影響なし**の正検知 |
| `契約書/` | 締結済みの雇用契約（更新時対応）と業務委託契約（適用外） |
| `共有フォルダ（未整理）/` | ファイル名と中身が一致しない文書、重複配置、AIへの指示文が仕込まれた文書 |

同じ「就業規則.docx」が `株式会社サクラベース/` と `共有フォルダ（未整理）/` の2か所にあります。
中身が同一なので**判定は1回だけ行われ、指摘は両方のファイルに出る**のが正しい動作です。

## 監視する正本

| 正本 | 法令ID | スナップショットの初期化 |
|---|---|---|
| 育児・介護休業法 | `403AC0000000076` | `--asof 2025-03-01` |
| 労働基準法 | `322AC0000000049` | `--asof 2019-03-01` |

```bash
python -m app.cli snapshot 403AC0000000076 --asof 2025-03-01
python -m app.cli snapshot 322AC0000000049 --asof 2019-03-01
python -m app.cli ingest --dir demo-data/監視対象
python -m app.cli run 403AC0000000076
python -m app.cli run 322AC0000000049
```

どの不適合がどの改正に紐づくかは `答え合わせ/違反の解説.md` を参照してください。

## 対応形式

**md / txt / docx のみ**です。PDF・pptx は対象外なので、追加する場合も入れないでください。

## 出典

`株式会社サクラベース/` および `サクラベース・ロジスティクス株式会社/` 配下の規程は、
厚生労働省「モデル就業規則」をもとに、架空の会社の規程として改変したものです。
[政府標準利用規約](https://www.digital.go.jp/copyright-policy)に基づき利用しています。

法令データは [e-Gov 法令検索](https://laws.e-gov.go.jp/)（デジタル庁）の法令API v2 より取得しています。
