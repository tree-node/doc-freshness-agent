このフォルダは、CLI パイプラインを動かすための最小サンプルです。
デモ本番用のデータ一式（ダミーデータ担当が作成中）に置き換えられる前提の暫定物です。

- 登場する会社名・人物名はすべて架空です。実在の企業・人物とは関係ありません。
- 内容は「2025年4月の育児・介護休業法改正より前のルール」に準拠して書いてあります
  （時間巻き戻しデモで「古くなった記述」として検知される想定）。
- 対応形式は md / txt / docx のみです。PDF は入れないでください。

含まれるもの:
- 就業規則.md              … 改正前の記述あり。期待する判定 = 影響あり（即時対応）
- コピー/就業規則.md        … 上と同一内容。1つの判定が両方に起票されることの確認用
- 雇用契約書_ひな形.md      … 今後の締結に使うひな形。期待する判定 = 影響あり（即時対応）
- 業務委託契約書.md         … 労働者ではないため労基法・育介法は適用外。期待する判定 = 影響なし（適用外）
