# ロゴ（案6「断層」）

条文の行が途中から横にズレている。改正とは足元が動くこと——それまで揃っていた社内文書が、
ある日から噛み合わなくなる。真ん中の朱が、ズレて古くなった一行。

| ファイル | 用途 |
|---|---|
| `mark-light.svg` | 明るい背景（スライド・資料） |
| `mark-dark.svg` | 暗い背景 |
| `mark-mono.svg` | 1色。`currentColor` なので文字色に追従する。印刷・モノクロ資料用 |
| `lockup-light.svg` | マーク＋名称の横組み |

アプリ内では `frontend/src/components/Logo.jsx` を使う（色は CSS 変数に追従）。
タブのアイコンは `frontend/public/favicon.svg`。

## 使うときの注意

- **28px 未満では行数を2本に減らす**（`Logo.jsx` が自動で切り替える）。3本のまま縮めると
  断層のズレが1px程度になり、ただの横棒に見える
- 朱（#B0482B）は状態色でもあるので、ロゴの朱を他のUI要素に流用しない
- `lockup-light.svg` の文字は明朝体。環境に無いと字面が変わるため、配布資料に使うときは
  文字をパス化しておくと安全
